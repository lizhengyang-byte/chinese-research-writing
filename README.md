# Chinese Research Writing — 中文研究写作 Skill

`chinese-research-writing` 是一个产出「出版级」中文长文写作的技能（Skill）：论文、研究报告、学术文章、深度特稿、评论、新闻特稿等。强调强证据、显结构、体裁控制，默认以严谨、有来源的叙述取代泛泛的 AI 式总结。

## 核心特性

- **证据地图先行**：写作前先识别核心定义、关键事实与数据、主要观点与反方、证据缺口、可直接支撑的来源
- **先检索后写作**：写作前执行中英文 web 检索，优先官方原始材料、学术数据库、权威机构发布
- **三种产出等级**：提纲版 / 初稿版 / 定稿版，按用户需要交付
- **四种写作通道**：学术论文 / 报告简报 / 深度文章·评论·特稿 / 新闻·解释性报道
- **长文档自动拆分**：超过 15000 字或任一章节超过 3000 字时，自动拆分为章节级 markdown 文件，并同时生成一份合并稿
- **GB/T 7714 引用**：默认中国国家标准引用格式，缺失元数据时宁缺勿造
- **质量验收清单**：交付前按 `references/acceptance_checklist.md` 复核

## 使用方式

将本项目（`SKILL.md` 所在目录）放入 AI 助手可识别的技能目录，然后发起类似请求：

> 请写一篇 5000 字的行业研究报告：「中国新能源汽车出口竞争力分析」，目标读者为行业研究人员，产出等级为初稿。

> 请为以下主题输出一份提纲版学术论文框架，并给出每章的证据与资料计划。

## 产出等级

| 等级 | 输出 |
|---|---|
| 提纲版 | 题目、写作目标与中心问题、结构提纲、证据与资料计划、风险点与补强建议 |
| 初稿版 | 完整正文 + 基础引用，证据薄弱处透明标注或审慎措辞 |
| 定稿版 | 结构收束、转承自然、引用完整、术语统一、无占位语句 |

## 体裁通道

- 学术论文 / 文献综述 / 述评
- 行业 / 政策 / 专题研究报告
- 深度文章 / 特稿 / 评论
- 新闻 / 解释性报道 / 事实核查式写作

## 写作标准

- 教科书式清晰度，拒绝空泛堆砌
- 研究型论证，拒绝口号式结论
- 完整段落推进（主张句 → 解释 → 证据 → 意义/局限/过渡），拒绝只列要点
- 有背景、有原理、有方法、有分析、有局限
- 未区分事实、分析、建议、价值判断的表达一律避免

## 边界

- 不虚构数据、引用、引文、页码、机构、调查结果与书目条目
- 来源冲突时明确说明并公允刻画分歧
- 证据薄弱时收缩论断，不夸大确定性；时效性强主题优先近 6–12 个月材料
