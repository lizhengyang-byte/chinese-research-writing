# GB/T 7714 quick guide

Use this file as a quick reminder for Chinese academic-style references.

## General rules
- Number references in order of appearance when using numeric citation.
- Keep the reference format consistent within one document.
- Prefer complete metadata, but never fabricate missing elements.

## Common entry patterns

### Book
[序号] 作者. 书名[M]. 出版地: 出版者, 出版年.

### Journal article
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.

### Newspaper article
[序号] 作者. 题名[N]. 报纸名, 年-月-日(版次).

### Thesis
[序号] 作者. 题名[D]. 城市: 单位, 年.

### Report
[序号] 作者/机构. 题名[R]. 城市: 机构, 年.

### Online resource
[序号] 作者/机构. 题名[EB/OL]. (发布日期)[引用日期]. 获取来源.

## Practical guidance
- When page numbers are unavailable for online materials, omit them rather than inventing them.
- For institutional authors, use the institution name consistently.
- For translated works, do not infer translator information unless verified.
