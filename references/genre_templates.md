# Genre templates

Use these as adaptable scaffolds. Do not copy them mechanically when the topic calls for a different structure.

## Thesis-style abstract template
- 研究背景与问题意识
- 研究对象与范围
- 材料、方法或分析路径
- 核心发现
- 理论或现实意义

## Literature review template
1. 研究主题与范围界定
2. 主要学术脉络
3. 代表性观点分类
4. 已有研究的贡献
5. 分歧、盲点与不足
6. 可进入的问题空间

## Case-study chapter template
1. 个案选择理由
2. 背景与关键变量
3. 事件过程 / 制度结构 / 技术路径
4. 机制分析
5. 与其他案例对照
6. 小结

## Investigative or feature article template
1. 导语场景或问题切口
2. 事实展开与背景
3. 关键人物、机构或议题链条
4. 证据节点与争议
5. 深层结构解释
6. 结尾回扣

## Policy report recommendation template
1. 问题定义
2. 政策目标
3. 约束条件
4. 方案比较
5. 建议路径
6. 风险与执行条件
